MCP (Model Context Protocol) 服务器，通过调用视觉语言模型 API 为 MCP 生态提供图像分析能力。特别适合那些使用不具备原生视觉能力的开源模型的场景，让任何 MCP 客户端都能分析和理解图像内容。

## 项目背景

MCP 是 Anthropic 推出的开放协议，用于连接 AI 模型与外部工具和数据源。虽然 Claude 等商业模型已具备原生视觉能力，但许多开源模型（如纯文本 LLM）并不支持图像输入。

Vision MCP 填补了这一空白：通过将图像分析封装为 MCP 工具，任何 MCP 客户端都可以调用外部 VLM（如 GPT-4o 或其他 OpenAI 兼容的视觉模型）来处理图像，无需模型本身具备视觉能力。

## 适用场景

- **开源模型增强**：为 Llama、Mistral 等纯文本模型添加视觉分析能力
- **统一工具接口**：通过 MCP 协议标准化图像分析调用方式
- **灵活的 VLM 选择**：可配置不同的视觉模型后端（GPT-4o、Claude、开源 VLM 等）
- **本地文件处理**：支持分析本地图像文件，自动处理路径和编码

## 核心功能

**`analyze_image` 工具**

```python
analyze_image(
    prompt: str,        # 分析指令
    image_source: str   # 图像来源
) -> str               # 分析结果
```

**支持三种图像输入：**

| 输入类型 | 示例 | 处理方式 |
|---------|------|---------|
| HTTP/HTTPS URL | `https://example.com/image.png` | 下载并转 Base64 |
| 本地文件路径 | `/path/to/image.jpg` | 读取并转 Base64 |
| Data URL | `data:image/png;base64,...` | 直接透传 |

**支持格式：** JPEG、PNG、WebP

## 系统架构

```
MCP 客户端（Claude Desktop / 其他客户端）
    ↓ (MCP 协议)
Vision MCP Server
    ↓
┌─────────────────────────────────┐
│  图像预处理                      │
│  - URL → 下载转 Base64           │
│  - 本地文件 → 读取转 Base64       │
│  - Data URL → 直接透传           │
└─────────────────────────────────┘
    ↓
OpenAI 兼容 VLM API
    ↓
分析结果返回客户端
```

## 技术实现

**FastMCP 框架**
基于 MCP 协议的 Python 框架，通过装饰器注册工具，自动处理协议通信。

**OpenAI 兼容接口**
支持任何 OpenAI 兼容的 VLM API，包括 OpenAI 官方、Azure OpenAI、以及各类兼容接口的开源模型服务。

**智能图像处理**
自动识别输入类型，统一转换为 Base64 Data URL。支持从 HTTP 响应头或文件扩展名检测图像格式。

## 安装配置

```bash
# 通过 uvx 直接运行
uvx vision-mcp
```

配置 MCP 客户端（以 Claude Desktop 为例）：

```json
{
  "mcpServers": {
    "Vision": {
      "command": "uvx",
      "args": ["vision-mcp"],
      "env": {
        "OPENAI_API_KEY": "your-api-key",
        "OPENAI_API_BASE": "https://api.openai.com",
        "OPENAI_MODEL": "gpt-4o"
      }
    }
  }
}
```
