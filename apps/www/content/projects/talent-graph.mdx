业务方对人才数据有大量自定义标签需求（院校层次、大厂经历、管理经验、量化背景等），同时底层数据存在普遍的非标问题：同一家公司有几十种写法（"字节"、"ByteDance"、"字节跳动(上海)有限公司"），同一所学校有简称、全称、历史名称。这两类需求交织在一起，但标签定义和清洗结果往往是零散的、临时的，缺乏统一维护和积累的机制。

talent-graph 是一个 PostgreSQL + pgvector 支撑的人才标签系统，用 CLI 和 Agent Skill 管理标签定义、实体标准化和画像生产。业务方按需定义标签，系统自动完成底层数据的标准化和匹配，标签和清洗结果持久化后所有分析直接复用。画像维度随标签定义持续扩充，支撑人才搜索、盘点、画像分析等场景，逐步构建更丰满的人才图谱。

## 两类标签

![Talent Graph 数据模型](/projects/talent-graph/data-model.svg)

系统区分两类标签，用不同策略处理：

| 类型 | 示例 | 判定方式 |
|------|------|---------|
| 名单标签 | 985 院校、MBB、TMD | 维护标准实体清单 + 别名映射，员工履历自动匹配 |
| 判定标签 | 有管理经验、量化背景 | Agent 通读员工 profile（教育、履历、简历）综合评判 |

名单标签依赖实体标准化：标签关联到标准实体（如"字节跳动"），标准实体关联到所有写法变体（如"字节"、"ByteDance"），员工履历中出现任何变体即命中。实体支持母子公司层级（阿里巴巴 → 菜鸟/蚂蚁/淘天），标签可选择是否覆盖子实体。新增实体时 pgvector 做语义去重，防止重复创建。

判定标签没有固定清单，由 Agent 按预定义的判定边界直接评判，结果写入员工标签关联。

## CLI

noun-verb 结构，所有命令返回统一的 JSON envelope：

```bash
talent-graph entity search 清华 --type school
# → { "ok": true, "status": "found", "data": [...], "meta": { "command": "entity.search" } }

talent-graph tag members 985 --format table
talent-graph alias list --entity-type company --limit 50
talent-graph employee get EMP001 --include tags,work,edu
```

6 个资源域：`tag`、`entity`、`alias`、`employee`、`audit`、`embedding`。默认只读模式，写入需显式切换到 `full` 模式。破坏性操作在同一事务内记录审计日志。

## Agent Skills

5 个操作 skill + 1 个编排 skill：

| Skill | 用途 |
|-------|------|
| `/define-tag` | 维护名单标签的实体名册，WebSearch 辅助验证标准清单 |
| `/gather-entity-aliases` | 从候选列表中提取指向目标实体的别名，适合学校等目标明确的场景 |
| `/attribute-raw-name` | 反向查找：一个原始写法属于哪个实体，可创建子实体处理子公司 |
| `/tag-employee` | 读取员工 profile，按判定标签边界评判 |
| `/query-talent-graph` | 只读查询，供下游消费方使用 |
| `/orchestrate-tagging` | 通过 [DataPilot](/projects/datapilot) Batch + Automation 编排上述 skill 的批量执行 |

每个 skill 配套领域判定 prompt（`prompts/` 目录），定义具体的分类规则和边界，如哪些学校算藤校、哪些公司算 MBB。

## 评测

`evals/` 目录包含 [Better Skills](/projects/better-skills) 评测工作区，覆盖 `define-tag`、`gather-entity-aliases`、`attribute-raw-name` 三个 skill 的测试用例和基线对比。

## 技术栈

- **运行时**：TypeScript + Bun（CLI），npm 全局安装可用
- **数据库**：PostgreSQL 14+ / pgvector / Drizzle ORM
- **向量**：OpenAI 兼容 Embedding API（可选，未配置时降级为文本匹配）
- **批量执行**：通过 [DataPilot](/projects/datapilot) Batch 系统调度
